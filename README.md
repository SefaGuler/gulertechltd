# gulertech.co.uk

Jekyll site served by GitHub Pages. No build step — push to `main` and GitHub builds it.

## Layout

```
_config.yml          site config + category (collection) definitions
_layouts/            default / note / category / page
_includes/           note-list partial
assets/css/          style.css (theme), syntax.css (rouge highlighting)
index.html           home: category grid + latest notes
<cat>/index.md       category listing page (one per collection)
_<cat>/*.md          published notes (generated by publish.sh from the private repo — do not edit here)
about/index.md       about page
feed.xml             RSS
```

Categories: `web`, `mobile`, `api`, `network`, `cloud`, `privesc`, `cve`.

## Notes

Notes are authored in the **private** `gulertech-research` repo and copied here with its `publish.sh`.
Do not hand-edit files under `_<cat>/` — they get overwritten on the next publish.

## Adding a category

1. Add a collection block to `_config.yml` (`title`, `icon`, `blurb`) plus a `defaults` entry.
2. Append the key to `category_order`.
3. Create `<key>/index.md`:
   ```yaml
   ---
   layout: category
   collection_key: <key>
   permalink: /<key>/
   ---
   ```
4. `mkdir _<key>` and add the same key to `CATEGORIES` in the private repo's `publish.sh`.
